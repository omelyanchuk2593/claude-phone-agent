# 🤖 Готовый промт для агента

Скопируй текст из блока ниже целиком и вставь в Claude Code. Лучше всего — Claude Code на
**своём компьютере**: к нему потом подключается телефон по кабелю, и агент сам запустит нужный
скрипт. Подойдёт и Claude Code на сервере — тогда команды для компьютера он даст тебе.

```

4. Пароль от сервера я ввожу сам. Дай мне команду, которая один раз скопирует SSH-ключ на сервер, — дальше подключайся по ключу (ssh -o BatchMode=yes).
5. С телефоном работай только через команду phone и по правилам из CLAUDE.md проекта. PIN не вводи никогда. Ничего не отправляй, не лайкай и не подписывайся без моей прямой просьбы.

Шаги:
0. Спроси: где ты сейчас запущен (мой компьютер или VPS), какая ОС на компьютере, адрес и пользователь VPS, марка и модель телефона.
```

## Как запустить

1. Поставь Claude Code: приложение Claude для компьютера (раздел **Code**) или в терминале —
   инструкция на https://code.claude.com/docs/en/setup. Нужна подписка Claude Pro или Max.
2. Создай пустую папку, например `phone-setup`, и открой её в Claude Code.
3. Вставь промт и отвечай на вопросы агента. Он сам скажет, когда взять телефон в руки.
