# claude-phone-agent

Ты управляешь настоящим Android-телефоном владельца через команду `phone`.
Телефон подключён к этому серверу по Tailscale (ADB по сети), адрес — в `config.local.json`.

## Как работать с телефоном

Цикл: **посмотреть → одно действие → проверить результат.**

```bash
phone status              # можно ли сейчас трогать телефон
phone ui                  # элементы экрана с номерами [N]; --find слово — фильтр
phone tap 12 -u           # нажать [12] и сразу показать новый экран
phone tap --text "Message" -u   # или --desc / --id / --xy X Y
phone type "текст" -u     # в поле в фокусе (или --into N)
phone scroll down -n 2 -u
phone back -u | phone home
phone open instagram -u
phone url https://instagram.com/<username> -u   # профиль без поиска
phone shot                # скриншот -> .cache/screen.png; смотреть через Read
phone tap --pic X Y       # нажать по координатам НА СКРИНШОТЕ
```

- `phone ui` дешевле скриншота — по умолчанию смотри экран через него. Скриншот нужен,
  когда важна картинка (фото, сторис, вёрстка без текста).
- `tap N` сверяет элемент со свежим экраном. Если экран уехал — `⚠️` и код 4:
  сними `phone ui` заново, не нажимай по старым координатам.
- Кириллица вводится нормально (accessibility setText, не `input text`).

## Правила (нарушение = вред живым людям или аккаунту)

1. **Телефон принадлежит человеку.** Код 2 (`⛔ телефон в руках` / `заблокирован`) —
   остановись и скажи владельцу. `--force` только если владелец прямо сказал «делай сейчас».
   PIN не вводить никогда, настройки телефона не менять.
2. **Отправка сообщения.** Перед нажатием «Send» убедись по экрану, что открыт диалог именно
   с нужным человеком (имя/ник в шапке переписки), и покажи владельцу текст, если он не сказал
   «отправляй без подтверждения».
3. **Опасные кнопки** (Unfollow, Block, Report, Delete, Log out, Удалить…) инструмент
   нажимает только с `--confirm`. Ставь его только по прямой просьбе.
4. **Follow / лайки** — только когда задача этого требует. Кнопки Follow стоят рядом с Message:
   нажимай по `--desc`/`--text`/номеру, не по координатам на глаз.
5. **Без массовости.** Instagram ограничивает аккаунты за всплески активности. По умолчанию:
   новых диалогов ≤ 10 в сутки, подписок ≤ 20, лайков ≤ 60, паузы между действиями как у
   человека. Больше — только по явному решению владельца.
6. Закончил задачу — `phone home`.

## Неполадки

| Сообщение | Что делать |
|---|---|
| `📵 … не отвечает` | телефон не в сети Tailscale или после перезагрузки слетел ADB по сети — владельцу: повторить шаг 5 инструкции (кабель + `setup/usb-tcpip`) |
| `📵 … не доверяет этому серверу` | владельцу: нажать «Разрешить» на телефоне |
| `⛔ …` (код 2) | телефон занят или заблокирован — подождать или спросить владельца |
| `⛔ телефоном сейчас управляет «…»` | другая сессия работает с телефоном; он закреплён за ней 90 с после её последнего действия |
| `⚠️ …` (код 4) | экран не тот — `phone ui` и заново |

`phone adb shell …` — сырой adb к телефону (у проекта свой adb-сервер на порту 5137).

## Устройство проекта

- `device.py` — связь с телефоном (uiautomator2 + adb), разбор экрана, проверка «занят ли телефон».
- `phone.py` + обёртка `phone` — команда. `config.json` — настройки по умолчанию,
  `config.local.json` (не в git) — адрес телефона и личные настройки.
- `.cache/` — последний экран, скриншот, отметка нашего последнего касания.
- Тесты: `.venv/bin/python -m pytest -q tests` (телефон не нужен).
